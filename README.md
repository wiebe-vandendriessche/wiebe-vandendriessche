# Wiebe Vandendriessche

Personal website and portfolio, built with [Hugo](https://gohugo.io/) and the [Blowfish](https://blowfish.page/) theme.

## Development

Initialize the theme submodule:

```sh
git submodule update --init --recursive
```

Preview the site locally:

```sh
hugo server
```

Build the production site:

```sh
./build.sh
```

The generated site is written to `public/`.
