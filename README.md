# Hi, I'm Wiebe Vandendriessche

PhD researcher at [IDLab](https://idlab.ugent.be/home), [Ghent University](https://www.ugent.be/), and [imec]. My research focuses on AI security in software supply chains: building transparency, accountability, and trust from data to deployed models.

## What I'm working on

- AI security, trustworthy AI, and software supply-chain security
- SBOMs, AI Bill of Materials (AIBOMs), and AI lifecycle transparency
- Contributing to [CRACY](https://cra-cy.eu/), a European project helping SMEs prepare for the Cyber Resilience Act
- Teaching, supervising master thesis topics, and contributing to technical workshops
